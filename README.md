## About

This fork adds two playback speed features to VLC media player:

1. **Speed-Adjusted Remaining Time Display** - A third time display mode that shows estimated real-world remaining time based on current playback rate. Click the time display to cycle through: Elapsed → Remaining → Speed-Adjusted (≈).

2. **Custom Speed Dialog** - Calculate the playback speed needed to finish a video within a specified duration ("Finish In") or by a specific clock time ("Finish By"). Accessible from the speed control widget or Playback → Speed menu.

## Status

These features are currently under review for inclusion in VLC 3.0.x. Please visit the merge request link above for the latest updates, discussion, and to provide feedback.
